# Genshin Impact World Quest Tracker

เว็บสำหรับติดตามความคืบหน้า World Quest ใน Genshin Impact โดยเปิดใช้งานผ่านเบราว์เซอร์

## วิธีใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์สมัยใหม่ ข้อมูลรายการเควสต์โหลดจาก `quest-data.js` โดยตรง ไม่ต้องติดตั้งแพ็กเกจหรือ build โปรเจกต์

ความคืบหน้าและเควสต์ที่เพิ่มเองจะบันทึกไว้ใน `localStorage` ของเบราว์เซอร์และอุปกรณ์ที่ใช้

## English

A browser-based tracker for Genshin Impact World Quests. Open `index.html` in a modern browser; the quest catalog is loaded from `quest-data.js`. No build step or package installation is required.

Progress and custom quests are stored in the browser's `localStorage` on the device you use.
